# Nimbus CRM — Deploy-mirror

This repository only hosts the **built static files** served at https://itsmelnd.github.io/nimbus-crm-site/

The application source code (including database schema, edge functions, and configuration) lives in the private repository [nimbus-crm](https://github.com/itsmelnd/nimbus-crm). This mirror is updated whenever a new version should go live.

**Security:** Account registration is disabled; accounts are created by an administrator. All data access is protected by Supabase Row Level Security — users only see their own company's data.
